# Introduction to Java EE 5 / 6

👉 Online course:
[https://stahe.github.io/en-javaee-juin-2012/](https://stahe.github.io/en-javaee-juin-2012/)

## Overview

This tutorial guide (June 2012) offers a practical introduction to **Java EE** through the development of a **three-tier** application:

* Overview
* Business logic
* Data access

The document is based on Java EE 5 and 6 and uses **Maven projects**.

## Technologies covered

### Web Application

* JSF (Java Server Faces)
* EJB3 or Spring (business layer)
* JPA (Hibernate / EclipseLink)

### Client/Server Application

* Swing (graphical client, Spring support)
* EJB3 or Web Services (server)

## Learning objectives

* Understand the architecture of a Java enterprise application
* Compare EJB3 and Spring
* Implement JPA for persistence
* Build a complete application with NetBeans

The document provides solution templates and leaves it to the student to complete certain sections.

## Prerequisites

* Knowledge of the Java language
* NetBeans IDE (approximately 1 GB of RAM recommended)
